## Why this project matters to the framework

DeepWell is the counterexample that keeps the cross-project taste profile honest. Its visual direction contradicts several things AdvPulse established:

| AdvPulse | DeepWell |
|---|---|
| Large border radius, soft containers | **Radius 0**, right angles |
| No glass or frosted treatment | **Liquid glass** as a deliberate device |
| Brand green as the single accent | Warm orange over grayscale |
| Color carries chart series | **Solid vs. hatched** carries committed vs. estimated |

Neither is wrong. They are different products. Any opinion that changes between these two belongs in a project profile, never in cross-project memory — that split is the reason the root `taste-profile.md` was rewritten.
